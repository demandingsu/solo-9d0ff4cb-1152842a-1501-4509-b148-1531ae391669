# 病例表脱敏 API（3×3 小人数遮蔽）

疾控中心统计员向外部研究人员发布 **3 区县 × 3 年龄组** 新发病例表
（每格 0–9 人）前的脱敏服务。提交原表，返回精确的行列合计与遮蔽后的
格值；保证每个被遮蔽的 1–4 人小格在公开信息下至少有两种可能人数，
避免小人数从合计中被倒推。

## 快速启动

```bash
docker compose up --build
```

然后打开 <http://localhost:8000/docs> —— Swagger UI 顶部有完整规则说明，
并内置三个可直接试跑的示例（请求体下拉框中选择）：

| 示例 | 请求表 | 结果 |
| --- | --- | --- |
| 可反推 | `[[2,3,9],[8,8,8],[8,8,8]]` | 只遮蔽 1–4 会被列合计倒推出 2 和 3；接口额外遮蔽 (1,0)、(1,1) |
| 需补遮蔽 | `[[2,7,6],[5,8,6],[7,5,6]]` | 最少 3 格补充遮蔽，字典序方案 [(0,1),(1,0),(1,1)] |
| 无解 | `[[1,0,0],[9,9,9],[9,9,9]]` | 行列合计强制 (0,0)=1，只返回 `not_publishable` |

curl 示例：

```bash
curl -s -X POST http://localhost:8000/mask \
  -H 'Content-Type: application/json' \
  -d '{"table": [[2, 3, 9], [8, 8, 8], [8, 8, 8]]}'
```

## 接口

### `POST /mask`

请求体：`{"table": [[0-9 整数] × 3] × 3}`（非 3×3、越界、非整数均返回 422）。

**可发布**（HTTP 200）：

```json
{
  "status": "publishable",
  "row_totals": [14, 24, 24],
  "column_totals": [18, 19, 25],
  "grand_total": 62,
  "cells": [[null, null, 9], [null, null, 8], [8, 8, 8]],
  "primary_masked_cells": [[0, 0], [0, 1]],
  "complementary_masked_cells": [[1, 0], [1, 1]],
  "masked_cells": [[0, 0], [0, 1], [1, 0], [1, 1]]
}
```

- `cells`：`null` 表示被遮蔽的格；
- `primary_masked_cells`：值为 1–4、按规则必须遮蔽的格；
- `complementary_masked_cells`：为满足“至少两种可能人数”而额外遮蔽的格，
  数量最少，并列时按坐标列表字典序选取；
- 坐标为 `[行, 列]`，从 0 开始。

**不可发布**（HTTP 200）：

```json
{"status": "not_publishable"}
```

无解时**只**返回该字段——不返回行列合计或任何格值，以免泄露原表。

## 安全准则与假设

- 攻击者可见：行列合计、公开格值、遮蔽位置、取值范围 0–9 以及遮蔽规则本身。
- 安全条件（按需求实现）：对每个值为 1–4 的格，在与“公开格值 + 行列合计 +
  0–9 范围”相容的所有原表中，该格至少呈现两种不同人数。遮蔽格在相容分析中
  取 0–9 全范围（攻击者无法区分首要遮蔽与补充遮蔽）。
- 该准则是需求给定的充分条件；它不防范利用“发布算法本身”的元推理等更强
  攻击模型。

## 算法

3×3 表在行列合计固定时有 4 个自由度：取左上角 2×2 为自由变量，其余 5 格由
合计唯一推出（`app/suppress.py`）。求解按补充遮蔽格数 k 递增、同 k 按坐标
字典序枚举候选集，第一个使所有首要遮蔽格满足“≥2 种可能”的候选即答案；
枚举上界为 2⁹ 个子集 × 10⁴ 个角格组合，配合 0–9 界剪枝，开销可忽略。

## 测试

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements-dev.txt
pytest tests/            # 或：python3 tests/test_suppress.py（核心算法，无依赖）
```

测试包含一个独立实现的暴力枚举器，用不同代码路径复核每个文档示例的
“≥2 种可能人数”性质及补充遮蔽的最小性。
